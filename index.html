How do I create a token? (10 seconds)
  1. Click Create a token ↗ above — it opens GitHub with the right scope pre-selected.
  2. Scroll down, click Generate token.
  3. Copy the token (starts with ghp_) and paste it here.

Scope needed: repo (classic token). Prefer fine-grained? Enable Contents: Read & write, Pages: Read & write and Administration: Read & write on your account, then pick the repo.
